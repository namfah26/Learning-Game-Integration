แก้ไขแดชบอร์ดเว็บ - รุ่นกดดูผล/ปิดผลเกม (2026-10-10)

แก้ไข 5 ไฟล์:
  js/teacher.js
  js/parent.js
  js/thaiw-dashboard.js
  css/app.css
  parent.html

การติดตั้ง:
1. สำรองโฟลเดอร์เว็บไซต์เดิมก่อน
2. แตก ZIP นี้ จากนั้นคัดลอกไฟล์/โฟลเดอร์ไปวางทับในเว็บไซต์หลัก โดยคงโครงสร้างเดิม
3. ใช้ Live Server เปิดเว็บไซต์ กด Ctrl+Shift+R หรือรีเฟรชแบบไม่ใช้แคช
4. เข้าเมนูผลนักเรียน กด ดูผลเกม ของแต่ละเกม จะเห็นชื่อเกมตรงกับรายการเกมที่เพิ่มไว้และปุ่ม ✕ ปิดผลเกม
5. ปุ่มปิดทำหน้าที่ซ่อนรายงานและเลื่อนกลับรายการเกม ไม่ลบคะแนน/ประวัติ

เปลี่ยนแปลงจากชุดไฟล์ล่าสุดที่ผู้ใช้ส่งมา:
- เอากล่องผล Unity ที่แสดงเองก่อนกดออกจากหน้ารายงาน
- รายงาน ThaiW เปิดตามชื่อเกมในรายการที่ครูเพิ่ม
- ทุกเกมมีปุ่มปิดผลเกมเดียวกัน ทั้งหน้าครูและผู้ปกครอง
- เกมที่ไม่มีคะแนนแสดงกราฟเวลาเข้าเล่นเมื่อกดดูผล
- ไม่แก้เกม Unity หรือ Animal Direction ที่อยู่ในโฟลเดอร์ games

หมายเหตุ: ไฟล์แพตช์เป็นไฟล์เว็บไซต์เท่านั้น ไม่ต้อง Build Unity ใหม่
