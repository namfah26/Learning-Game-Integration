เว็บไซต์เวอร์ชันปรับหน้าจอ ThaiW และแสดงสรุปการเข้าเล่น

1. คัดลอกเฉพาะไฟล์ games/ThaiW/index.html ไปทับ index.html ของ Build WebGL ล่าสุดที่คุณใช้งานได้แล้ว (ถ้าคุณ Build แบบ Compression Disabled ใหม่ อย่าคัดลอกไฟล์ Build เก่าจาก ZIP นี้กลับไปทับ)
2. หน้า Teacher > ผลการเรียนรู้ > เลือกนักเรียน แสดงเวลาเปิดหน้าเกมและคะแนนที่เกมส่งมาจริง พร้อมคำเตือนเมื่อไม่มีข้อมูล
3. ระบบ ThaiW ยังไม่ส่งคะแนน/คลิก/เวลาแต่ละด่านออกจาก Unity; แยกภาษาไทยกับผลไม้ไม่ได้แน่ชัดจาก WebGL โดยไม่เพิ่มการส่งเหตุการณ์ใน Unity
4. ระยะเวลาเปิดหน้าเกมเป็นการวัดจากหน้าเว็บ; อาจไม่ครบเมื่อเบราว์เซอร์ถูกปิดกะทันหัน
5. ผลเกรด D ไม่ถูกคำนวณเพิ่ม
6. การบันทึกผ่าน localStorage ใช้ได้ในเบราว์เซอร์เครื่องเดิม; การรวมผลหลายเครื่องต้องตั้งค่า backend ที่เชื่อถือได้
7. ทดสอบผ่าน local web server ไม่ใช่ file://
