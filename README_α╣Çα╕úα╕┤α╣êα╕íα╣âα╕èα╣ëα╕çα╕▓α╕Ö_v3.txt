MyWebsite Integrated v3 — ตัวอย่างระบบครบชุด
==============================================

สิ่งที่ปรับใน v3
-----------------
1) หน้าแรกแยกผู้ใช้: ครู / นักเรียน / ผู้ปกครอง
2) ครูมี Login ทดลอง
   Username: admin
   Password: 12345678
   และมีปุ่มกลับหน้าเลือกผู้ใช้
3) ข้อมูลนักเรียนเพิ่ม
   - รหัสนักเรียน
   - ชื่อ-นามสกุล
   - วันเกิด
   - เบอร์โทรนักเรียน
   - ชื่อผู้ปกครอง
   - ความสัมพันธ์
   - เบอร์โทรผู้ปกครอง
   - ที่อยู่
4) ผู้ปกครองแก้ไขข้อมูลติดต่อได้
   - เบอร์โทรนักเรียน
   - ชื่อผู้ปกครอง
   - ความสัมพันธ์
   - เบอร์โทรผู้ปกครอง
   - ที่อยู่
   รหัสนักเรียน / ชื่อ / วันเกิด ให้ครูเป็นผู้แก้ไข
5) การลบนักเรียน/เกม เปลี่ยนเป็น “ปิดใช้งาน”
   ประวัติเดิมไม่ถูกลบ และสามารถเปิดใช้งานกลับได้
6) ครูเพิ่มเกมได้พร้อมคำอธิบายเกม
   คำอธิบายจะแสดงบนหน้าของนักเรียน
7) หน้าครูดูผลแบบ
   เลือกนักเรียน -> โปรไฟล์ -> เกม -> Dashboard ของเกม
   ไม่แสดงผลทุกคนรวมกันเป็นตารางยาวหน้าเดียว
8) เกม Animal Direction
   - เมื่อเข้าจากระบบนักเรียน จะใช้ชื่อเด็กจาก Login อัตโนมัติ
   - ไม่ต้องให้เด็กกรอกชื่อซ้ำ
   - ซ่อนปุ่ม Save เดิม
   - จบเกมบันทึกผลอัตโนมัติ
   - เด็กเห็นผลแบบง่าย: คะแนน + แถบ 4 ทิศ + ข้อความแนะนำ
   - ไม่แสดงรายละเอียดรายด่านให้เด็ก
   - ปุ่ม “เล่นอีกครั้ง” เปิดรอบใหม่
   - ปุ่ม “ออกจากเกม” ออกจากหน้าต่างเกมจริง
9) ครูและผู้ปกครอง
   - เห็นคะแนนล่าสุด
   - Radar 4 ทิศ
   - กราฟแนวโน้มคะแนน
   - ประวัติการเล่น
   - ครูสามารถเปิดรายละเอียดรายด่านของแต่ละรอบได้
10) เกมอื่นที่ยังส่งคะแนนไม่ได้
   - ระบบยังบันทึกเวลาเข้าเล่น
   - Dashboard จะแจ้งว่าเกมยังไม่มีข้อมูลคะแนน

หมายเหตุเรื่องข้อมูล
-------------------
รุ่นนี้ยังใช้ LocalStorage เป็นฐานข้อมูลหลักสำหรับการทดลอง
ดังนั้นครู/นักเรียน/ผู้ปกครองควรทดสอบบน Browser + Origin เดียวกัน
เช่น http://127.0.0.1:5500/

Google Sheet / Apps Script ที่เตรียมไว้ในโฟลเดอร์ backend ยังใช้สำหรับผลเกมได้
แต่สำหรับระบบจริงหลายอุปกรณ์ ควรย้าย Students / Guardians / Games / Results
ไปฐานข้อมูลกลางที่มีระบบยืนยันตัวตนและกำหนดสิทธิ์ผู้ใช้
